# WebUI 配置

ICY 管理台参考 [AstrBot 的 WebUI 交互](https://docs.astrbot.app/use/webui.html)，采用左侧分组导航、顶部状态栏、卡片列表与弹窗编辑。默认浅色主题，可在设置中选择深色或跟随系统；侧边栏可收起，小屏幕使用抽屉导航。页面地址包含当前栏目，刷新或浏览器前进、后退可恢复栏目。

## 页面与编辑流程

- **仪表盘**：服务状态、累计任务、进行中与已完成任务、当前配置、快捷入口和最近任务。
- **配置文件**：AI 配置下的模型、人格、能力、高级分组，以及平台与权限。顶部搜索可跨分类查找配置项，按 `/` 聚焦搜索。
- **模型服务 / 人设管理**：卡片展示摘要，点击编辑打开弹窗；新建人设也通过弹窗填写。
- **插件管理**：插件卡片显示开关、状态与独立配置入口；关键词回复支持规则编辑、删除和上移，拟人化输出支持标点处理与命令范围设置。命令列表展示当前内置插件的命令。
- **数据与日志**：任务记录按状态筛选，实时日志按文本筛选，统计显示任务状态分布。每 15 秒更新运行数据，不覆盖配置草稿。
- **设置**：主题与侧边栏偏好，保存在当前浏览器。

配置字段的修改保留在页面草稿；弹窗中点击“应用此配置”会校验并更新草稿，取消不应用弹窗中的编辑。JSON 编辑遵循相同流程。右下角“保存配置”才会写入服务器并触发机器人重新加载；“撤销修改”恢复上次保存的配置。离开页面或退出登录时提醒未保存的修改。正在作为默认人设或分配给会话的人设不能直接删除。

## 配置范围

- **平台与权限**：私聊开关、群命令免 @ 开关、群 OpenID 白名单、封禁用户 OpenID。开启群命令免 @ 后，群内 `/calc 1+2*3` 等已注册命令无需 @，普通对话仍需 @；命令沿用群与用户授权。新版本默认开启，旧设置文件缺少此字段时使用该默认值。
- **AI 配置**：Agent 总开关、默认模型、人设分配、工具开关、并发、队列、每轮模型与工具调用次数、输出 token 上限。
- **模型**：已配置模型的模型 ID、服务地址、工具调用能力。模型别名和密钥环境变量名由部署配置固定；密钥值不在网页中展示或保存。
- **人设**：默认人设、最多 32 个人设、群与私聊 OpenID 分配。用户消息不能切换人设。
- **插件**：实用命令、持久记忆、关键词回复的开关与参数。启用关键词回复后，群内命中现有规则的消息无需 @，沿用群与用户权限、规则范围及冷却。使用方法见 [内置功能插件](plugins-built-in.md)。

直接命令继续由命令模块处理；Agent 开启后，普通消息进入 Agent 任务。保存会校验配置并写入 `ICY_BOT_SETTINGS` 指定的独立 JSON 文件，服务重启后生效。两个页面同时编辑时，较旧页面的保存会被拒绝，刷新后可以继续。

## 部署结构

WebUI 服务读取 `ICY_WEB_MANIFEST` 指定的插件清单，提取默认配置。机器人启动时，如果设置了 `ICY_BOT_SETTINGS`，会读取并覆盖 `app-runtime` 的对应模块配置。运行时设置独立于发布目录，更新版本不会清空网页修改。

生产部署通过 `icy-settings.path` 监听 `/var/lib/icy/config`，WebUI 原子写入 `/var/lib/icy/config/bot-settings.json` 后自动重启 `icy.service`。WebUI 需要对该目录的写权限，机器人需要读权限。不要让 WebUI 对发布目录或 systemd 单元拥有写权限。

公网访问应使用 HTTPS。当前服务器使用 IP 地址证书，管理台地址是 `https://101.34.239.66:5099/`；证书短期有效，由 `icy-cert-renew.timer` 定期续期，并在续期后重启 WebUI 加载新证书。QQ AppSecret、模型 API Key 和管理密码哈希仍由服务器环境文件管理。

本地验证：`npm run verify`，其中 `web-settings-smoke` 覆盖登录鉴权、CSRF、草稿校验不落盘、配置保存、模块覆盖和并发编辑冲突。`POST /api/settings/validate` 与保存接口共享配置校验，并要求同源与 CSRF 校验。

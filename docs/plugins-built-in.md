# 内置功能插件

以下插件以 App Module 运行，共享现有命令路由、身份和权限服务。在 WebUI 的「插件」页面设置开关和参数，保存后重启加载。只有群白名单内、私聊已开启且未封禁的用户能够使用。

## 实用命令（utility）

| 命令 | 功能 |
|---|---|
| `/roll`、`/roll 2d6` | 掷骰子，数量上限可配置，面数 2–100000 |
| `/choose 火锅 \| 烧烤 \| 拉面` | 从 2–20 个选项中随机选择 |
| `/whoami` | 显示 QQ 平台事件提供的用户 OpenID、群 OpenID、场景和角色 |
| `/plugins` | 查看当前启用的命令插件 |

直接命令不调用 LLM。插件通过 `PluginCommands` 注册命令，命令路由统一授权并将已启用命令加入 `/help`。禁止重复命令名和覆盖已有内置命令。

## 持久记忆（memory）

| 命令 | 功能 |
|---|---|
| `/remember 我喜欢简短回答` | 主动保存一条记忆 |
| `/memories`、`/memories 2` | 分页查看当前会话中自己的记忆 |
| `/forget 12` | 删除自己的指定记忆 |
| `/forget all` | 清空当前会话中自己的记忆 |

记忆按机器人、场景、群和用户隔离。相同用户在另一个群或私聊中不能读取这里的记忆。只有用户的直接命令可以写入或删除，LLM 注册的 `memory_search` 工具只读，查询参数不能指定用户或会话。

WebUI 中开启「允许 Agent 检索用户记忆」会将 `memory_search` 加入工具权限。记忆以工具结果中的用户数据返回给 Agent，不拼接到系统提示词，不自动跨会话共享。`/reset` 仅清空对话记录；主动记忆需用 `/forget` 删除。

生产部署在模块配置中设置 `dbPath=/var/lib/icy/plugins/memory.sqlite`；也可用 `ICY_MEMORY_DB_PATH`。不配置时使用内存数据库并在日志中提示。保存命令按平台消息标识去重，重投递不重复新增。每用户条数与单条字数可配置；调低上限不会删除旧数据，停用插件也不会删除数据库。

## 关键词回复（auto-reply）

WebUI 中添加规则，填写 ID、关键词、匹配方式、回复、场景、指定群和冷却秒数。启用后，群内命中规则的消息无需 @机器人；该行为独立于「群命令免 @」开关。规则按页面顺序选择第一条匹配项；支持完全匹配和包含关键词，区分大小写、忽略消息首尾空白。指定群列表为空表示所有已授权群，仍检查群白名单与用户权限。

处理顺序是直接命令 → 关键词回复 → Agent。斜杠命令不匹配关键词。规则命中后不进入 LLM；相同会话和规则处于冷却期时保持静默。冷却状态在重启后重置。该插件默认关闭且规则为空。

运行 `npm run plugins-smoke` 验证命令权限、会话隔离、记忆持久化与消息去重、只读工具、规则范围和冷却；`npm run web-settings-smoke` 验证配置保存和旧设置兼容。

## 拟人化输出（humanize）

在 WebUI → 插件管理 → 拟人化输出中启用，点击配置调整处理方式，保存后生效。默认开启，不产生额外模型调用。

| 设置 | 默认 | 行为 |
|---|---|---|
| `enabled` | `true` | 插件总开关 |
| `stripTerminalPunctuation` | `true` | 去掉末尾中英文句号、问号、感叹号：`。！？.!?` |
| `perLine` | `true` | 处理每行末尾；关闭时只处理整条回复的最后一个非空行 |
| `includeCommands` | `false` | 是否同时处理斜杠命令的文本回复 |

例如 `收到。` → `收到`，`真的？！` → `真的`，`你好。明天见！` → `你好。明天见`。句中标点保留，原始换行和空白保留，不生成空回复。

采用保守的格式保护：代码围栏（含未关闭围栏）、缩进代码、含行内代码的行、引用、表格、公式、完整 JSON、HTML/XML、链接和文件名等保留原文。省略号保留语气；单独的标点和数字列表标记不删除。它不是完整的 Markdown/编程语言解析器；需要精确保留的内容建议放在代码围栏中。

同步回复通过 App 消息链的外层 middleware 处理；后台 Agent 在 `Runs` 投递前调用同一个 `Humanize` 服务。模型/工具输入、任务结果和会话历史保留原始内容；处理只改变发给用户的文本。停用或不加载模块时沿用原始输出，`Runs` 对该模块使用可选依赖。

运行 `npm run humanize-smoke` 验证格式保护、处理范围、同步链和后台发送，并确认原始模型结果仍保留。
